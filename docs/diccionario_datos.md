# Diccionario de datos (resumen 3FN)

**rol**(id_rol PK, nombre UNIQUE, descripcion) | **usuario**(id_usuario PK, correo UNIQUE, clave_hash CHAR64, salt, estado, intentos, fecha) | **usuario_rol**(id_usuario+id_rol PK compuesta, fecha) FK CASCADE/RESTRICT | **perfil**(id_perfil PK, id_usuario UNIQUE FK CASCADE → 1:1, nombres, apellidos, documento UNIQUE, telefono, direccion, foto) | **inmobiliaria**(id_inmobiliaria PK, id_usuario UNIQUE FK, nombre_empresa, nit UNIQUE) | **ciudad**(id_ciudad PK, nombre UNIQUE) | **tipo_propiedad**(id_tipo PK, nombre UNIQUE) | **propiedad**(id_propiedad PK, id_inmobiliaria FK RESTRICT 1:N, id_ciudad FK, id_tipo FK, titulo, precio>0, matricula UNIQUE, estado, destacada, activo baja lógica) | **imagen_propiedad**(id_imagen PK, id_propiedad FK CASCADE 1:N, url) | **caracteristica**(id_caracteristica PK, nombre UNIQUE) | **propiedad_caracteristica**(PK compuesta N:M) | **cita**(id_cita PK, id_propiedad FK, id_cliente FK, fecha_hora, estado, UNIQUE(id_propiedad,fecha_hora)) | **solicitud**(id_solicitud PK, id_propiedad FK, id_cliente FK, tipo, estado) | **documento_solicitud**(id_doc PK, id_solicitud FK CASCADE) | **favorito**(PK compuesta usuario+propiedad) | **auditoria**(id PK, id_usuario FK SET NULL, accion, detalle, fecha).

3FN: sin transitivas (ciudad/tipo/característica en tablas propias), todo depende de la PK.
