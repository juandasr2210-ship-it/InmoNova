# Tablero Padlet — Guía de evidencia (Scrum 30pts)

El profe pide evidencia del tablero. Como Padlet no se puede exportar desde aquí, haz esto (5 min):
1. Entra a https://padlet.com → Crear → Tablero → nombre `InmoNova - Scrum`.
2. Crea 4 columnas: `Backlog | Sprint 1 | Sprint 2 | Sprint 3`.
3. Agrega tarjetas con las HU del `product_backlog.md` (copia título + prioridad + DoD).
4. Mueve todo a `Hecho`, toma captura y súbela como `docs/padlet_captura.png`.
5. Pega el link público del Padlet en tu README y en la sustentación.

Columnas sugeridas + etiquetas Alta (rojo), Media (amarillo), Baja (verde). Commits frecuentes simulan el tablero: usa el historial Git.
